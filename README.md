# 성적 관리 프로그램

## 무엇을 하나요 (What)

성적 CSV 파일을 읽어 유효한 점수와 건너뛴 줄을 구분합니다.

## 왜 만들었나요 (Why)

실제 파일에는 빈 값, 범위를 벗어난 점수, 잘못된 형식의 데이터가 섞여 있을 수 있기 때문에 이를 안전하게 처리하기 위해 만들었습니다.

## 어떻게 쓰나요 (How)

```bash
python load_scores.py scores.csv
```

## 어떻게 테스트하나요

```bash
pytest test_load_scores.py
```

정상 입력, 예외 상황, 점수 경계값에 대한 테스트가 모두 통과하는지 확인합니다.

## 파일 구성

- `load_scores.py` : 성적 CSV 파일을 읽고 유효한 데이터와 건너뛴 줄을 구분하는 프로그램
- `test_load_scores.py` : 정상·예외·경계값을 검사하는 pytest 테스트
- `scores.csv` : 실행 예시용 성적 데이터
- `empty.csv` : 헤더만 있는 테스트 데이터
- `weird.csv` : 잘못된 값이 포함된 테스트 데이터
- `README.md` : 프로그램 실행 및 테스트 방법 설명
