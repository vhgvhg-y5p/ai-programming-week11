
## 12주차 데이터 분석

### 데이터
- 파일: scores_2026.csv
- 출처: AI협업프로그래밍 12주차 실습 제공 자료
- 원본: 114행, 5열
- 정제 후: 100행

### 열 설명
- 학번: 학생 식별번호
- 이름: 학생 이름
- 반: 소속 반
- 과목: 수학, 영어, 프로그래밍
- 점수: 0~100점 범위의 성적

### 데이터 정제 기준
- 결측값: 점수가 없는 6행 삭제
- 중복값: 완전히 중복된 4행 삭제
- 공백: 반과 과목의 앞뒤 공백 제거
- 이상값: 0점 미만 또는 100점 초과인 4행 삭제

### 결측값 처리 이유
점수가 없는 행은 실제 성적을 확인할 수 없으므로
임의의 점수로 대체하지 않고 삭제했다.
임의로 평균값 등을 입력하면 분석 결과가 왜곡될 수 있기 때문이다.

### 분석 및 검증
- 반별·과목별 평균, 중앙값, 최댓값 계산
- 전체 합계 7484.0 확인
- mini.csv 손계산 검증
- pytest 테스트 4개 통과
